# Zhuyin Keyboard with Pinyin Lookup

An interactive reference tool that maps Zhuyin (Bopomofo) symbols to their Pinyin romanization equivalents, designed for Mandarin learners who need to bridge between the two phonetic systems.

## What Is Zhuyin?

Zhuyin (注音符號), also known as Bopomofo, is the official phonetic system used in Taiwan to represent Mandarin sounds. Unlike Pinyin (which uses Latin characters), Zhuyin uses 37 dedicated symbols — 21 consonants, 13 vowels, and 4 tone marks — making it a distinct learning curve for those already familiar with Pinyin romanization.

## Features

- **Full symbol coverage** — all initials (聲母), finals (韻母), and tone marks displayed on a single keyboard layout
- **Live Pinyin search** — type any Pinyin syllable (e.g. `bo`, `zh`, `ai`, `ang`) and matching Zhuyin characters light up with an animated golden glow
- **No dependencies** — pure HTML5, CSS3, and vanilla JavaScript; works offline and loads instantly
- **Fully responsive** — adapts to desktop, tablet, and mobile layouts

## Use Cases

- Mandarin learners transitioning between Pinyin and Zhuyin input methods
- Educators building phonetic reference materials
- Developers needing a lightweight Zhuyin reference embedded in a web page
