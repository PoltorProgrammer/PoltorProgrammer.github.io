## 🌿 What is the Digital Garden?

This repository hosts my personal portfolio and blog, built entirely with **vanilla HTML, CSS, and JavaScript**. The garden structure allows visitors to browse projects and writings through two main sections:

1. **The Blog (`/blog.html`)**: Where the repositories get context — the reasoning behind the architecture, how the scope evolved, and the cross-cutting ideas that don't fit in a README.
2. **The Garden (`/garden.html`)**: An interactive catalog of my original creations, organized into seven specialized domains.

---

## 🗂️ The Seven Domains

My work sits at the intersection of science and software development, grouped into these key areas:

*   **🌿 Nature**: Biology, zoology, botany, and natural science projects.
*   **🧠 AI & Data**: Extraction pipelines, NLP, and intelligent document processing.
*   **🏥 Medical**: Healthcare systems, clinical trial analysis, and medical extraction tools.
*   **🎨 Designs**: Interactive user interfaces, modern component designs, and vector graphics.
*   **🔧 Tools**: Converters, markdown editors, code tools, and helper libraries.
*   **🌏 Language**: Phonetic keyboards, input tools, and multilingual learning utilities.
*   **🎮 Games**: Browser-based interactive environments, visual experiments, and retro games.

---

## 🛠️ Tech Stack & Features

*   **Core Logic**: Vanilla ES6+ JavaScript.
*   **Styling**: Pure CSS3 with custom variables, smooth transitions, and responsive grid/flexbox layouts.
*   **Particle Background**: Interactive HTML5 Canvas particle system on the hero section.
*   **Typewriter Effect**: Lightweight custom typist animation on the landing page.
*   **Data-Driven Blog Feed**: Asynchronous JSON fetching for blog posts and project archives.

## 🚀 Local Setup

Since this is a static website, you don't need compilation or complex build tools. You can run it locally with any simple HTTP server.

### Option 1: VS Code Live Server
If you use VS Code, install the **Live Server** extension, click **"Go Live"** in the status bar, and it will open the website at `http://127.0.0.1:5500`.

### Option 2: Python HTTP Server
Run the following command in the repository root directory:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.

### Option 3: Node.js (http-server)
Install and run `http-server` via npm:
```bash
npx http-server
```
