# Google Colab Notebooks

A curated collection of Google Colab files (`.ipynb`) and Jupyter Notebook experiments, documenting machine learning model evaluations, data extraction trials, and automated pipeline scripts.

## Overview

This repository represents your active prototyping sandbox. It houses experimental scripts designed to run in cloud environments, letting you leverage free GPU resources to evaluate neural architectures, test optical character recognition (OCR) parameters, and run natural language processing checks.

## Key Notebook Categories

- **NLP & Classification** — Prototyping classification models to parse text patterns, evaluate sentiment scores, and categorize entries.
- **Computer Vision & OCR** — Experimental runs with libraries like Tesseract, EasyOCR, and PDF parser engines to test text extraction accuracy from scanned documents.
- **API Trials** — Safe environments to test model prompts, parse JSON outputs, and measure response latencies across different AI providers.
- **Data Cleanup Pipelines** — Pandas and NumPy scripts to sanitize datasets, handle null records, and prepare clean JSON structures for production use.

## Workflow Value

Many production pipelines inside **MediXtract** and the **Analisi SUS** script originated as quick, messy trials inside these Google Colab notebooks. Prototyping in Colab ensures dependencies are resolved before code is migrated into production files.

> [!TIP]
> These notebooks contain direct links to open them instantly in Google Colab, allowing you to run and modify the active code blocks in one click.
