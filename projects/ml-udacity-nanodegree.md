# Udacity Machine Learning Engineer Nanodegree Portfolio

This repository documents the full portfolio of projects, coding assignments, model training notebooks, and system architectures developed during your tenure in the rigorous Udacity Machine Learning Nanodegree program.

## Overview

The Nanodegree program focuses on advanced software engineering methodologies applied to ML problems: training models on local machines or AWS SageMaker, implementing reinforcement learning agents, and validating performance metrics.

## Key Projects Featured

- **Cap-Stone Project** — A comprehensive, end-to-end machine learning system covering problem definition, data ingestion, exploratory data analysis (EDA), model training, hyperparameter optimization, and final deployment.
- **AWS SageMaker Pipelines** — Exercises building, deploying, and auto-scaling production-ready prediction endpoints using AWS compute instances.
- **Customer Segmentation (Unsupervised Learning)** — Applying Principal Component Analysis (PCA) and K-Means clustering to divide demographic datasets into clean consumer profiles.
- **Supervised Learning Classifiers** — Comparing decision trees, support vector machines (SVM), and gradient boosted classifiers to optimize predictions on demographic census data.

## Professional Competencies Gained

- Rigorous model evaluation: ROC/AUC curves, confusion matrices, F1-scores, and cross-validation techniques.
- Structured hyperparameter tuning: Grid search and randomized search algorithms.
- Deep understanding of deep learning structures (CNNs, RNNs) and reinforcement models.

> [!NOTE]
> All projects in this repository passed Udacity's strict peer-review and code-quality validation criteria prior to graduation.
